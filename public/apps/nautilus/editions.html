01 — The System
One set of tokens, many worlds

Each Edition is just a table of values. Swap the table, and the entire app re-dresses live — the same primitives every native component reads from.

Color roles

paper · panel · ink · ink-soft · accent · rule · depth-rail. Semantic, never literal.

Type pairing

AaAaAa

A reading face + a UI face + a mono. Scale & rhythm fixed by the system.

Space & radius

4-pt rhythm, one radius family. Density is a token too.

Motion & texture

fold ⟶ paper
collapse: 220ms
ease: (.2,.8,.2,1)

Grain, glow, scanlines — atmosphere is a token, not an afterthought.
